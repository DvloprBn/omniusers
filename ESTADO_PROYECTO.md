## 1. Dónde estamos

- Backend (`omniuser_backend`, NestJS+Prisma+Postgres): registro público, login en 3 pasos (correo → contraseña → 2FA si aplica), refresh/logout con rotación real de sesión, roles dinámicos (CRUD real), administración de usuarios, 2FA real (TOTP + 10 códigos de recuperación de un solo uso), rate limiting real, detección real de fuerza bruta (login y 2FA).
- Frontend (`omniuser_frontend`, Next.js): sitio público simulado, login de 3 pasos en pantallas separadas, panel de administración (`/admin`, solo `admin`/`super`) con Usuarios/Roles, área de cuenta (`/cuenta`, cualquier rol) con activación real de 2FA (QR real), atajo de desarrollo (`/dev/cuentas-de-prueba`) para saltar entre roles con login real, nunca un bypass.

- 3 cuentas de prueba reales sembradas (`super`/`admin`/`usuario`, password `TestOnly123!`), 2FA reseteado a limpio tras las pruebas.
